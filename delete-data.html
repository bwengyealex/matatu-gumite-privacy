Matatu Gumite - Data Deletion Request

Matatu Gumite is a card game published by DJ Makerenda Games. Players may request deletion of data associated with their use of Matatu Gumite.

How to Request Data Deletion

To request deletion of your data, send an email to:

bwengyealex0@gmail.com

Use the subject line "Matatu Gumite Data Deletion Request". Please include your in-game player name or other information necessary to identify the game data you want deleted.

Data That May Be Deleted

A deletion request may include data such as:

  • Player name
  • Anonymous player/account identifier
  • Uploaded profile picture
  • Selected profile avatar
  • Game statistics, including matches played and wins
  • Leaderboard information associated with the player

Data Retention

After a valid deletion request is received and the relevant player data is identified, the requested data will be deleted unless retention is required for security, fraud prevention, legal, or regulatory purposes.

Contact

For questions regarding data deletion or privacy, contact: bwengyealex0@gmail.com
